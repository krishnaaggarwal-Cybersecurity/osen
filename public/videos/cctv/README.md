# CCTV Footage Upload Directory

Place your CCTV camera video clips (.mp4, .webm) into this directory:
public/videos/cctv/

### Recommended Filenames:
- cam-07.mp4 (or cam-07-nh48.mp4) - CAM-07 NH-48 Km 112 Feed
- cam-04.mp4 (or cam-04-cp.mp4) - CAM-04 CP Radial Road 3 Feed
- cam-12.mp4 (or cam-12-aiims.mp4) - CAM-12 AIIMS Flyover Feed
- cam-19.mp4 (or cam-19-dnd.mp4) - CAM-19 DND Toll Gate Feed
- cam-02.mp4 (or cam-02-cybercity.mp4) - CAM-02 Cyber City Tunnel Feed

The player in the dashboard will automatically loop whichever video is selected for that camera!
